# Pomoc systemu Pracownia INF03:

## POMOC/HELP
Wyświetla pomoc.
## INIT
Inicjalizuje bazę danych.

# Więcej komend dostępnych po inicjalizacji:
## SCAN
Skanuje foldery w poszukiwaniu nowych arkuszy.
## DEL
Usuwa dany arkusz z bazy.
## LS
Wyświetla dostępne arkusze w kolejności od najstarszego do najnowszego.
## LS S < STATUS >
Wyświetla arkusze z danym statusem w kolejności od najstarszego do najnowszego ze wskazanym statusem.
## LS P < PRZEDMIOT >
Wyświetla arkusze z danym przedmiotem w kolejności od najstarszego do najnowszego ze wskazanym statusem.
## FIND
Szuka arkusza po roku, miesiącu, numerze.
## START
Rozpoczyna / wznawia pracę z arkuszem. Wymaga id arkusza.
## START LAST
Wznawia pracę nad ostatnio używanym arkuszem.
# Jeśli STARTED:
## PAUSE
Kończy pracę z arkuszem w stanie niedokonczone.
## END
Kończy pracę z arkuszem stanie zakonczone.
## REPAIR
Resetuje kontener do stanu zerowego.
